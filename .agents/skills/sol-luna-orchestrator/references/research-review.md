# Scientific and engineering research profile

Apply this supplemental checklist when `mode=research` or the task involves numerical simulation, experimental data, fitting or scientific graphics.

- Specify governing equations, parameter symbols, physical units, and boundary/initial conditions.
- Check dimensional consistency and conversions (for example m/mm, Pa/kPa/MPa).
- Distinguish observed data, fitted parameters, assumptions, and model predictions.
- For numerical solvers, check convergence, sensitivity, numerical stability, and conservation when applicable.
- For regression or parameter fitting, document objective functions, constraints, train/test separation, and uncertainty.
- For plotting, ensure labels/units are correct and outputs are reproducible from source data.
- Do not manufacture experimental measurements or assign fictitious fit quality.
- Record software versions, random seeds, run commands and expected outputs when feasible.
- If Abaqus, FLAC3D, MATLAB or another proprietary tool is unavailable, perform only available static checks and clearly identify unexecuted validation.
